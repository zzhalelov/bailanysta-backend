Bailanysta — Социальная сеть с ИИ-ассистентом
Bailanysta (каз. «В связи» / «Связь») — это полнофункциональное веб-приложение социальной сети с поддержкой AI-генерации контента, кастомным национальным оформлением, мгновенной сменой пользователей и интерактивным взаимодействием (лайки, комментарии, подписки).
📌 Краткое описание проекта
Приложение представляет собой современную платформу для публикации постов и общения. Основные возможности:
Лента публикаций: просмотр всех записей и фильтрация по персональной ленте подписок («Мои подписки»).
AI-генератор постов (Gemini): встроенный модальный ассистент для быстрой генерации постов по текстовому промпту с автоматической вставкой черновика в форму создания.
Система подписок и социальные взаимодействия: возможность подписываться на пользователей прямо из карточек постов или их профилей, ставить лайки и оставлять комментарии с сохранением даты и времени публикации.
Переключение пользователей (Multi-User Switch): быстрая смена активного аккаунта через кастомное выпадающее меню в Navbar без необходимости разлогина для удобного тестирования взаимодействия между пользователями.
Управление контентом: авторасширяемое текстовое поле ввода, удаление собственных постов с каскадным удалением связанных комментариев и кастомным модальным окном подтверждения.
Адаптивный тематический UI: светлая и тёмная темы, прозрачный традиционный казахский орнамент (қошқармүйіз) на заднем фоне и адаптивность под мобильные устройства.
🛠 Выбор технического стека и его обоснование
Backend: Java 17, Spring Boot 3, Spring Data JPA, H2 Database / PostgreSQL.
Почему: Spring Boot предоставляет надежную корпоративную архитектуру, встроенную поддержку REST API, высокую производительность и готовую интеграцию с JPA для обработки каскадных связей (например, удаление поста вместе с комментариями).
Frontend: React 18, TypeScript, Vite.
Почему: Vite обеспечивает мгновенную сборку и HMR (Hot Module Replacement) при разработке. TypeScript гарантирует строгость типов моделей (Post, Comment, SubscriptionStatus) и исключает ошибки на этапе компиляции.
Styling & UI: Чистый CSS3 с CSS Custom Properties (переменными) + Lucide React (иконки).
Почему: Отказ от тяжелых UI-библиотек (Material UI, Ant Design) позволил полностью контролировать стилизацию компонентов, реализовать плавные CSS-анимации, кастомный UserDropdown и гибкую адаптацию казахского орнамента в фоновом SVG/PNG паттерне.
🚀 Инструкции по установке и запуску
Предварительные требования
Java JDK 17 или выше
Node.js v18+ и npm
1. Запуск Backend (Spring Boot)
Клонируйте репозиторий и перейдите в директорию бэкенда:
cd bailanysta-backend
Соберите и запустите приложение:
./mvnw spring-boot:run
Бэкенд запустится на http://localhost:8080 и автоматически заполнит начальные данные через DataInitializer.
2. Запуск Frontend (React + Vite)
Перейдите в директорию фронтенда:
cd bailanysta-frontend
Установите зависимости:
npm install
Добавьте изображение логотипа и орнамента в папку public/:
public/logo.png — фавикон для вкладки браузера и шапки.
public/kazakh-ornament.png — фоновый паттерн.
Запустите сервер разработки:
npm run dev
Приложение будет доступно по адресу http://localhost:5173.
📐 Процесс проектирования и разработки
Разработка проходила по итеративной методологии:
Проектирование базы данных и API:
Определение сущностей (Post, Comment) и связей One-to-Many с каскадным удалением (CascadeType.ALL, orphanRemoval = true).
Разработка REST endpoints: /api/posts, /api/posts/{id}/like, /api/posts/{id}/comments, /api/subscriptions, /api/ai/generate.
Разработка UI/UX и адаптивного интерфейса:
Верстка карточек постов, модального окна AI-генератора и страницы профиля.
Внедрение сквозной подстройки темы (Light/Dark) через data-theme на элементе document.documentElement.
Интеграция социализации и мульти-аккаунта:
Создание кастомного React-компонента UserDropdown с поддержкой закрытия по клику вне области (click outside).
Реализация динамического обновления профиля при смене пользователя через useParams и useNavigate.
Полировка визуального стиля:
Оформление фонового казахского орнамента с помощью linear-gradient маски для сохранения читаемости текста.
Добавление авторасширения textarea под длинный сгенерированный текст.
💡 Уникальные подходы и методологии
Кастомный компонент селектора пользователей (UserDropdown): Замена стандартного системного HTML <select> на кастомный стилизованный React-компонент позволила обойти ограничения системного рендеринга на macOS/Windows и создать единый стиль выпадающего списка.
Фоновая маска с нативным орнаментом: Использование комбинированного фона linear-gradient(rgba(...), rgba(...)), url('/kazakh-ornament.png') позволило регулировать прозрачность узора через альфа-канал градиента без редактирования исходного PNG файла.
Автоуправление высотой ввода (textareaRef): Автоматический перерасчет scrollHeight при вставке или вводе текста гарантирует, что даже длинный сгенерированный ИИ ответ гармонично умещается в поле ввода.
Переключение аккаунтов «на лету»: Использование localStorage и реактивного состояния currentUser имитирует настоящую сессию, позволяя тестировать подписки, комментарии и лайки от лица разных пользователей без необходимости переавторизации.
⚖️ Принятые компромиссы (Trade-offs)
Хранение сессии в localStorage вместо JWT/OAuth:
Компромисс: Авторизация упрощена до выбора пользователя из списка.
Причина: Проект ориентирован на быстрый демонстрационный и тестовый сценарий (дизайн, социальный flow, интеграция с ИИ).
База данных H2 (In-memory) / Каскадные связи JPA:
Компромисс: Данные сбрасываются при перезапуске сервера (за исключением initial seed).
Причина: Позволяет запускать проект на любой машине без развертывания внешнего сервера СУБД.
Использование кастомных CSS-переменных вместо Tailwind CSS:
Компромисс: Требовалось вручную писать CSS-классы для адаптивности и анимаций.
Причина: Полная свобода в настройке специфических стилей орнамента, темной темы и эффектов наведения.
🐛 Известные проблемы и ограничения
CORS при DELETE-запросах во время локальной разработки:
В некоторых окружениях браузер может блокировать DELETE-запросы без явно настроенных CORS-заголовков (@CrossOrigin или WebMvcConfigurer) на бэкенде. Для предотвращения этого в проекте настроена глобальная конфигурация CORS и прокси Vite.
Кэширование изображений браузером (Favicon):
При замене файла logo.png браузер может временно отображать старую иконку вкладки из кэша. Решается жестким обновлением страницы (Cmd+Shift+R / Ctrl+F5).
Мобильное отображение фонового орнамента:
На некоторых мобильных устройствах с включенным сильным экономителем батареи свойство background-attachment: fixed может отключаться браузером для оптимизации скролла.
